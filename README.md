# სიგარა (Sigara)
Local build (JDK 17 + Android SDK 34 + Gradle 8.7, or just open in Android Studio):
    gradle wrapper --gradle-version 8.7
    ./gradlew assembleDebug
APK: app/build/outputs/apk/debug/app-debug.apk
Or push to GitHub: Actions -> "Build APK" -> download artifact "sigara-debug-apk".
